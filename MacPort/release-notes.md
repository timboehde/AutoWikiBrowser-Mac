Unofficial native Mac version of AutoWikiBrowser, built on AWB's own WikiFunctions engine.

**Requirements:** an Apple silicon Mac (M1 or later) with macOS 12 or later. Nothing else to install.

**Installing**
1. Download the `.zip` below and unzip it.
2. Move **AutoWikiBrowser** to your Applications folder.
3. Open it. macOS will block it the first time because it isn't signed with an Apple Developer ID: go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only need to do this once.

To edit English Wikipedia, your account must be approved on [Wikipedia:AutoWikiBrowser/CheckPageJSON](https://en.wikipedia.org/wiki/Wikipedia:AutoWikiBrowser/CheckPageJSON), as with Windows AWB. Logging in with a [bot password](https://en.wikipedia.org/wiki/Special:BotPasswords) is recommended.

This is not an official AWB release; please report Mac-specific problems on this repository's Issues page.
